# sokolik.dev

Одностраничное портфолио на React и Vite. Кнопка Admin открывает вход по адресу `/#admin`. В админке можно опубликовать или удалить работу. Обложки PNG, JPEG, WebP и GIF до 5 МБ загружаются напрямую в Vercel Blob.

## Деплой на Vercel

1. Подключите этот репозиторий к проекту Vercel. Используйте корень репозитория, Vite и Node.js 24.
2. Подключите к проекту публичное хранилище Vercel Blob. Vercel добавит `BLOB_READ_WRITE_TOKEN`.
3. В настройках Environment Variables добавьте `ADMIN_PASSWORD` с паролем входа и `ADMIN_SESSION_SECRET` со случайным ключом длиной от 32 символов. Пример генерации ключа: `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`.
4. Включите переменные для нужного окружения (Production или Preview) и запустите новый деплой.

Пароль и ключ используются только в Vercel Function. После входа браузер получает подписанную сессию в cookie HttpOnly на 12 часов. Смена пароля или ключа делает предыдущие сессии недействительными. Работа становится видна в портфолио после сохранения её записи в Vercel Blob.

## Локальная разработка

```sh
npm ci
npm run dev
npm run build
```

Vite запускает интерфейс. Для проверки админки вместе с Vercel Function используйте `npx vercel dev` с подключённым проектом и переменными окружения для Development.
